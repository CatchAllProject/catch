O QUE É O SAVE READER?

O Save Reader é uma ferramenta criada para interpretar arquivos de save e transformar seus dados em informações fáceis de visualizar.

A proposta é simples: carregar um save, extrair seus dados e apresentar tudo de maneira organizada, visual e familiar.

O projeto faz parte do CatchAll Project, uma iniciativa experimental voltada para ferramentas, sistemas e experiências relacionadas ao universo Pokémon.
